## Selected repositories

### [Mega Saver](https://github.com/haJ1t/MegaSaver)

**A local-first context engine for AI coding agents.**

Evidence-preserving compression, cross-agent project memory, and decision traces that help agents spend fewer tokens without losing the evidence they need. Every compressed result remains expandable to its original output.

`TypeScript` `Node.js` `MCP` `Turborepo`

[Website](https://megasaver.dev/) · [npm package](https://www.npmjs.com/package/@megasaver/cli) · [Source code](https://github.com/haJ1t/MegaSaver)

### [Tactix](https://github.com/haJ1t/Tactix)

**Football tactics, transformed into an interactive analysis workspace.**

A full-stack analysis prototype that turns StatsBomb event data into pass networks, player centrality metrics, tactical-pattern signals, shot-quality insights, and downloadable PDF match reports.

`Python` `Flask` `React` `D3.js` `scikit-learn`

[Explore Tactix](https://github.com/haJ1t/Tactix)

### [Eventoo](https://github.com/haJ1t/eventoo-frontend)

**Event management from discovery to operations.**

A SvelteKit and Supabase frontend covering events, venues, organisers, attendees, reporting, and account workflows. Built with reusable UI components, filtering, search, and responsive navigation.

`SvelteKit` `TypeScript` `Supabase` `Tailwind CSS`

[Explore Eventoo](https://github.com/haJ1t/eventoo-frontend)

### [Hawk-Eye Card Games](https://github.com/haJ1t/hawk-eye-card-game)

**Higher/Lower and Blackjack, built with care beyond the basic rules.**

Betting, streak multipliers, persistent stats, responsive animations, and a glassmorphism interface. Includes a dependency-free Python CLI and a zero-build vanilla JavaScript GUI with a Fisher-Yates shuffle.

`Python` `Vanilla JavaScript` `CSS Animations` `Fisher-Yates`

[Explore Hawk-Eye](https://github.com/haJ1t/hawk-eye-card-game)
